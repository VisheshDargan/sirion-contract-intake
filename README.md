# Sirion contract intake: prototype

A working prototype of AI-powered contract intake for Sirion (PM case study). Open `index.html`, or the deployed site.

- `index.html`: the whole prototype (walkthrough, prototype, solution, why intake, stakeholders, problem, success metrics).
- `api/sirion.js`: the live Sirion AI endpoint used by "Check a new email" and "Ask Sirion AI". It needs `ANTHROPIC_API_KEY` set in the Vercel project's environment variables. Without it, the prototype shows that Sirion AI isn't set up and offers "Fill in by hand".

All people, companies and figures in the scenario are illustrative.
